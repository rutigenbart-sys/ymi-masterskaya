# Мастерская YMi — как запустить сайт

## 1. Выложить на GitHub Pages
1. Создайте репозиторий, загрузите в него всё содержимое папки «сайт» (вместе с файлом `.nojekyll`).
2. Settings → Pages → Branch: main / root.
3. Когда купите домен: Settings → Pages → Custom domain, и добавьте файл `CNAME` с доменом.

## 2. Заказы в Telegram (выберите вариант)
Откройте `config.js`.
- **Ничего не меняя** — заказ открывается в Telegram на номер 89266701649 готовым сообщением (клиент нажимает «Отправить»).
- **Автоматически, как «настоящая» форма:** создайте бота у @BotFather, узнайте свой chat_id (бот @userinfobot), затем:
  - лучше: разверните `worker/telegram-worker.js` в Cloudflare Workers (бесплатно), впишите адрес в `ORDER_ENDPOINT`;
  - проще: впишите `BOT_TOKEN` и `CHAT_ID` (токен будет виден в коде сайта).

## 3. Домен и цены
- Адрес сайта для SEO — в исходниках (`build.py`, строка `SITE_URL`). Сейчас там заглушка https://ymimasterskaya.art.
- **Цены в каталоге — ЗАГЛУШКИ.** Поменять: `products.py` (поле price) → запустить `python3 build.py`.
- Реквизиты оператора для политики конфиденциальности — `OPERATOR_DETAILS` в `build.py`.

## 4. Проверка на компьютере
Дважды щёлкните «Запустить локально.command» и откройте http://localhost:8000
